## 🚀 Teknologi

- **Pure Single-File HTML** — tidak perlu install apapun
- **Live XAU/USD Price** via Gold API (fallback simulasi otomatis)
- **TradingView Widgets** — chart & ticker tape live
- **LocalStorage** — data tersimpan di browser Anda
- **Web Speech API** — Voice Co-Pilot (Bahasa Indonesia)
- **Telegram Webhook** — kirim sinyal & log otomatis ke Telegram

## 🖥️ Cara Pakai

### Online (GitHub Pages)
Langsung buka: **[https://brodhani.github.io/gold-desk](https://brodhani.github.io/gold-desk)**

### Offline / Lokal
```bash
git clone https://github.com/Brodhani/gold-desk.git
cd gold-desk
# Buka index.html di browser — atau jalankan server lokal:
python3 -m http.server 8080
# Buka http://localhost:8080
```

## ⚙️ Konfigurasi Telegram (Opsional)

1. Buat bot di [@BotFather](https://t.me/BotFather) → dapatkan **Token**
2. Dapatkan **Chat ID** Anda dari [@userinfobot](https://t.me/userinfobot)
3. Di Gold Desk → klik ikon **Telegram** di topbar → masukkan Token & Chat ID
4. Sinyal & log transaksi akan otomatis terkirim ke Telegram Anda
